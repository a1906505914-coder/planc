【审计小程序多人协作接入说明】

大家好，审计底稿自动化小程序现已支持多人协作（代码 Git 共享 + 数据共享盘 + 各人本机计算），欢迎接入。接入约需 20 分钟，按下面 4 步操作：

一、安装 WorkBuddy（自带 Python 运行环境）
  下载安装 WorkBuddy 桌面版（腾讯 CodeBuddy 出品），我们跑程序用的 Python 就是它自带的，无需另装。

二、拉取程序代码（首次）
  打开命令行（cmd），执行：
    git clone \\192.168.0.231\git_repos\audit_miniapps.git audit
    cd audit
  注：192.168.0.231 是共享服务器 IP（如连不上，确认已在同一局域网、防火墙已放行文件共享）。

三、配置环境（一次性）
  · 数据指向共享盘：
    set AUDIT_DATA_ROOT=\\192.168.0.231\底稿测试
  · 缓存指向本机（防止多人写共享盘缓存互相干扰）：
    set AUDIT_CACHE_DIR=C:\audit_cache
    set AUDIT_GL_CACHE_DIR=C:\audit_gl_cache
  · 依赖（如需虚拟环境）：
    python -m venv .venv && .venv\Scripts\activate && pip install -r requirements.txt

四、开始使用
  · 一键跑 AH 三集团全套：run_audit.bat run_all.py ah
  · 跑单数据包：run_audit.bat run_all.py <数据包目录>
  · 单科目：python run_u8_on_sap.py --subj tax
  · 详细命令表见 README.md §一/§三 和 docs/本机服务器接入指南.md §四

三条铁律（务必遵守）：
  1. 一律经 run_audit.bat 运行（裸 python 会导致底稿行序不稳定）；
  2. 改代码前 git status、改后跑 python tests/test_architecture.py + python tests/smoke_test.py 全绿再提交，合并需审查；
  3. 数据安全：所有账套数据进 AI 对话前先本地脱敏（脱敏.bat / mask 工具），真实主体名称不进入对话；同一账套不要两人同时全量跑（程序会自动拦截）。

有任何问题看 docs/ 下三份文档：审计小程序总览与团队协作说明.md（架构）、本机服务器接入指南.md（接入）、以及 README.md（操作）。
