# 数据包清单（随小程序打包，发给同事的验收依据）

> 用途：一句话说清「程序包 vs 数据包」的边界、数据包内要放哪些文件、同事机器上三步验收怎么跑。
> 权威来源：`paths.py`（账套清单与路径锚点）、`preflight_check.py`（运行前强制自检）、`requirements.txt`（依赖锁定）。
> 版本：v1.0　日期：2026-09-01

---

## 一、边界：程序包 ≠ 数据包

| 包 | 内容 | 由谁准备 |
|---|---|---|
| **程序包** | 小程序整个目录（脚本 + `requirements.txt` + `paths.py` 配置 + `skills/` 方法论 + `docs/` 文档） | 打包时自带，同事**无需**单独准备 |
| **数据包** | 账套原始数据（见第二节），**不含在程序包里** | 你按本清单整理后另传 |

核心规则（`paths.py` 铁律）：程序代码内**禁止**出现任何数据绝对路径；数据路径唯一锚点 = 环境变量 `AUDIT_DATA_ROOT`（缺省 `D:\底稿测试`）。**换机器只需设这一个变量，代码零改动。**

---

## 二、数据包结构（`<DATA_ROOT>` 下布局）

```
<DATA_ROOT>\            ← 环境变量 AUDIT_DATA_ROOT 指向的父目录
├── ACB\                ← 账套目录，账套名 = 目录名，必须与下表一致（唯一事实来源 = ACCT_NAMES）
├── GJX\
├── ARF\  GFY\  AYL\  AJJ\  ADZ\  AJ\  AQ\  AFJ\  AS\  ATT\  AZ\
├── AH\                 ← SAP 主账套（88 家主体，集团模式）
├── ADF\                ← 300 集团（3100-6900，网银核对主账套）
└── XBJ\                ← 水利水电（U8 集团级 201 实体）
```

**账套目录共 16 个**（`paths.py` 的 `ACCT_NAMES` 原样）：`ACB, GJX, ARF, GFY, AYL, AJJ, ADZ, AJ, AQ, AFJ, AS, ATT, AZ, AH, ADF, XBJ`

每个账套目录内，按需放入（`preflight_check.py` 校验的三大件已加 ★）：

| 子目录 / 文件 | 用途 | 适用 |
|---|---|---|
| ★ `科目余额表/` | TB，底稿"余额 vs 发生额"权威依据；**TB 第 7 列 = 权威科目清单** | SAP 账套（AH/ADF 等） |
| ★ `序时账/` | 综合查询明细表 = GL 明细，13 类科目生成器主输入（凭证级取数） | SAP 账套 |
| ★ `底稿/` | **输出目录**（生成结果自动落这里，缺失会自建，请确认可写） | 所有账套 |
| `prepared/` | 集团模式三件套数据文件（如 `prepared\CNY\`、`groups\` 等） | 集团模式（AH 等） |
| `辅助核算余额表/` | 往来科目挂账对象（客户/供应商） | 往来/应收应付底稿 |
| `科目明细账/` 等企业导出表 | 应收/应付底稿**必须消费企业导出表（已净额化）**，非原始 GL | 相关账套 |
| `网银/` CSV 流水 | 银行核对/货币资金底稿 | 专项（ADF 网银核对） |
| 固定资产卡片、租赁合同、函证回函、开户清单、银行流水 | 固资 4-sheet、使用权资产、函证核对、开户清单 OCR | 专项 |

## 四、同事端三步验收命令

> 前置要求：Windows + Python **3.11 或 3.12**（`requirements.txt` 锁定 pandas 3.0.5 需 ≥3.11；过新版本可能踩 paddle 兼容坑）。

**① 装依赖**
```bat
pip install -r "程序包目录\requirements.txt"
```
> 若不做 OCR（RapidOCR/Paddle ），可先装核心子集跑通底稿链路：`openpyxl xlsxwriter pandas numpy xlrd`。

**② 设数据根（重开终端生效）**
```bat
setx AUDIT_DATA_ROOT "D:\账套数据"
```
（PowerShell 等价：`[Environment]::SetEnvironmentVariable('AUDIT_DATA_ROOT','D:\账套数据','User')`）

**③ 运行前自检（先于一切跑数）**
```bat
python "程序包目录\preflight_check.py" AH
```
不带账套名 = 检查全部账套；也支持 `--out <输出目录>`、`--skip-hardcode`（硬编码扫描误报时用）。

**一键验收**（CMD，依次执行）：
```bat
pip install -r "程序包目录\requirements.txt"
setx AUDIT_DATA_ROOT "D:\账套数据"
python "程序包目录\preflight_check.py"
```

## 五、验收标准（看自检返回码）

| 返回码 | 含义 | 处理 |
|---|---|---|
| **0** | 全部通过，可以安全运行 | ✅ 直接进 `run_audit.bat` |
| **1** | 有警告，可运行但建议确认 | 逐个看 ⚠️ 项（多为目录缺失，补上更稳） |
| **2** | 有阻断，必须先处理 | 看 ⛔ 项，常见：三大件目录缺失 / 磁盘 <2GB / Excel 锁文件（文件正被打开）/ 同数据包被他人锁占用（`.audit.lock`） |

## 六、红线提醒（打包前必读）

1. **脱敏**：数据包传出前过一遍 `mask_*` / `desensitizer.py`；底稿交付前同样要跑。主体真实名称不进对话、不进共享包。
2. **数据安全**：程序与数据分离，同事只拿到自己需要的那部分账套即可，不必整包全给。
3. **并发**：多用户并发锁/缓存隔离已内置——同事在自己机器跑**不影响**你本机；同数据包被他人处理时自检会 BLOCK。
4. **编码**：SAP GBK 大文件读取依赖机器区域设置，同事机器建议与你同区域配置（简体中文）。
