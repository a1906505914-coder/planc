## 二、本机（服务器端）待你手动配置（GUI 操作，一次性）

> 以下需要你在 Windows 上操作（需要管理员权限；命令行的 `net share` 被安全策略禁用）：

1. **共享数据盘**（成员读账套数据）：
   - 右键 `D:\底稿测试` → 属性 → 共享 → 高级共享 → 勾选"共享此文件夹"；
   - 权限：**成员账号=读取**（数据只读，防误改）；你自己=完全控制；
   - 记下共享名（默认 `底稿测试`）。

2. **共享 Git 仓库目录**（成员 clone/push）：
   - 右键 `D:\git_repos` → 属性 → 共享 → 高级共享 → 勾选"共享此文件夹"；
   - 权限：**成员账号=读取/写入**（push 需要写 bare 仓库）；
   - 共享名默认 `git_repos`。

3. **网络可达**：
   - 确认本机在局域网（当前 IP `192.168.0.231`）；
   - 防火墙放行：控制面板 → Windows 防火墙 → 高级设置 → 入站规则 → 放行"文件和打印机共享(SMB-In)"（445 端口）；
   - 本机需**常开**（成员随时可能拉数据/推代码）。

4. **成员账号**（可选，更安全）：
   - 设置 → 账户 → 家庭和其他用户 → 添加成员账号；或沿用现有 Windows 账号；
   - 数据共享建议只读、Git 共享才开放写。

## 四、成员日常操作手册（调用程序）

> 与主机操作完全一致，差异只有：代码=自己 clone 副本、数据=共享盘只读、缓存=本机本地。

### 4.1 常用命令

| 场景 | 命令 |
|---|---|
| AH 三集团全套（自动指纹回归+完整性检查） | `run_audit.bat run_all.py ah` |
| 单数据包全套 | `run_audit.bat run_all.py <数据包目录>` |
| 改代码后单模块回归 | `run_audit.bat regress_module.py <模块名> [--allow 白名单]` |
| 专项调试 | `run_audit.bat <程序>.py <数据包目录>` |
| 集团往来科目重跑 | `python run_u8_on_sap.py --group --subj current_account` |
| 断点续跑 | `python resume_yy.py` |
| 收口 | `python finalize_yy.py` |
| 完整性检查 | `python wp_completeness_check.py`（一键扫全部底稿出总表） |

### 4.2 run_u8_on_sap 常用参数

```bat
python run_u8_on_sap.py [账套路径] [主体...] --subj bank,current_account   :: 只跑指定科目
python run_u8_on_sap.py <数据包目录> --group                               :: 集团模式
python run_u8_on_sap.py <数据包目录> --out-dir <输出目录> --skip-check      :: 指定输出/跳过质检
```

### 4.3 改代码流程（防回退）

1. `git status` 看改动 → 改代码；
2. 改公共层先跑 `python tests/test_architecture.py` + `python tests/smoke_test.py` 全绿；
3. 单模块回归 `run_audit.bat regress_module.py <模块>` + 指纹对比；
4. 全部确认后 `git add + commit + push`（合并需审查者确认）；
5. 重跑期间不改代码；全量只发生在收口。

### 4.4 常见问题速查（详见 README §五）

| 现象 | 处理 |
|---|---|
| `PermissionError` / 底稿没更新 | 目标文件被 Excel/WPS 打开，关闭后重跑 |
| 底稿"整份空白"但 TB 有数据 | 对照 `self_check` 提示定位模块取数边界 |
| 行序每次不同 | 必须经 `run_audit.bat`（裸 `python` 行序随机） |
| XBJ 等大表 OOM | 已 xw 流式化；仍卡查 `.cache` 是否过大可清 |
| 同数据包被占用 | `.audit.lock` 提示 → 等超时(30分钟)或确认无人运行后删锁 |

## 五、协作规则（已写入团队协作文档 §6.5/6.6）

1. 改代码前 `git status`，改后跑 `python tests/test_architecture.py` + `python tests/smoke_test.py` 全绿再提交；
2. 同数据包并发已被 `.audit.lock` BLOCK（30 分钟 TTL）；定时任务**单主负责制**；
3. 指纹基线**只由合并审查者更新**；合并前跑回归；
4. 数据安全红线不变：**所有数据进 AI 对话前本地脱敏**，真实主体名称永不进入对话；
5. 数据只读挂载（`AUDIT_DATA_ROOT` 指向共享盘），输出写本地或共享产出区（按账套×年度×生成者分工）。
