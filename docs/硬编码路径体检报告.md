## 六、改造建议

1. **统一模式**：所有 A 类文件改为 `from paths import DATA_ROOT, APP_ROOT, DATA_DIRS, acct`，禁止各文件重复写默认值（防漂移）；
2. **优先级**：先改 A1（AH 主线 16 个共享脚本）——它们是团队第一轮就要共同跑的；A2/A3/A4 随用随改；
3. **特殊处理**：`lease_ledger.py` 的 DATA_ROOT 覆盖必须优先修（漏网点）；
4. **改后验证**：`git status` 确认无意外改动 → 单科目样本跑一轮 → 指纹回归 → 再全量；
5. 顺手把 C 类注释里的真实路径换成 `<DATA_ROOT>` 占位符（铁律第 5 条）。
